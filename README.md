Sou desenvolvedor **fullstack com base sólida em backend**, focado em construir sistemas com **arquitetura limpa**, **integrações**, **segurança**, **observabilidade** e **deploy em cloud**.

Hoje, meu foco principal está em:
- **APIs REST e regras de negócio**

- **Sistemas próximos de produção**, não apenas protótipos
